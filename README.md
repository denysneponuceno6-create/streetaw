# Street — Landing Page

## Como usar

1. Extraia o ZIP
2. Abra a pasta `site`
3. Abra o arquivo `index.html` no navegador
   (ou rode: `python3 -m http.server 8080` dentro da pasta site)

## Estrutura (importante para as imagens carregarem)

```
site/
├── index.html
├── images/
│   ├── logo-street.jpg
│   └── products/          ← fotos dos tênis (prod-01.jpg …)
└── README.md
```

As imagens dos produtos novos estão em `images/products/`.
Os produtos antigos usam links do CDN.
